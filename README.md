# 🛒 Olist E-Commerce Business Intelligence Project

## 🎯 Objective
Build a complete End-to-End Data Analysis and Business Intelligence Project using Brazilian E-Commerce dataset by Olist.

## 📦 Dataset
- 📌 Source: Kaggle - Brazilian E-Commerce Public Dataset by Olist
- 🔗 Link: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- 📁 Total Files: 9 CSV files

## 📂 Project Structure
task 2/
|-- 📓 olist_main_project.ipynb     
|-- 🌐 olist_streamlit_app.py       
|-- ⚙️ etl_pipeline.py              
|-- 📋 requirements.txt             
|-- 📄 README.md                    

## ✅ Tasks Completed
- ✅ Task 1:  Data Collection (9 CSV files + Exchange Rate API)
- ✅ Task 2:  Data Cleaning and Preprocessing (Nulls, Duplicates, Outliers)
- ✅ Task 3:  Exploratory Data Analysis (10 Visualizations)
- ✅ Task 4:  Business KPIs (Revenue, CLV, Churn, AOV, Delivery Rate)
- ✅ Task 5:  Advanced SQL Queries (Joins, Subqueries, Window Functions)
- ✅ Task 6:  Power BI Interactive Dashboard (1 Page)
- ✅ Task 7:  Sales Forecasting using Prophet ML Model
- ✅ Task 8:  Streamlit Web App Deployment
- ✅ Task 9:  ETL Pipeline with Logging
- ✅ Task 10: GitHub Upload

## 📊 Business KPIs
- 💰 Total Revenue
- 🛒 Average Order Value (AOV)
- 👤 Customer Lifetime Value (CLV)
- 📉 Churn Rate
- 📈 Retention Rate
- 📅 Monthly Sales Growth Rate
- 🚚 Average Delivery Time
- ⏰ On-Time Delivery Rate
- ⭐ Average Review Score
- ❌ Order Cancellation Rate

## 🛠️ Tech Stack
- 🐍 Python - Data Analysis and ML
- 🐼 Pandas and NumPy - Data Manipulation
- 📊 Matplotlib and Seaborn - Visualizations
- 🔮 Prophet - Sales Forecasting
- 🗄️ SQLite - SQL Queries
- 📊 Power BI - Interactive Dashboard
- 🌐 Streamlit - Web App Deployment
- 🐙 Git and GitHub - Version Control

## 🚀 How to Run

📥 Install Dependencies
pip install -r requirements.txt

▶️ Run Streamlit App
streamlit run olist_streamlit_app.py

⚙️ Run ETL Pipeline
python etl_pipeline.py
